# Briefs

A brief is a short file that says what a batch of creatives is for. `/produce-creatives
briefs/<file>.md 3` turns one into three finished variants.

## Standing rules, for every batch

- **Say only what the ad does.** No statistics, no "only N can", no rankings, no rewards.
  If the headline describes the situation (an opponent who is ahead, a timer, a last
  round), the settings must make it so.
- **Our own name and look.** No other game's name, logo or characters.
- **One idea per variant.** Each variant is there to be compared with the others; say in
  one sentence what it tests.
- **Winnable.** A player who follows the hand wins. An ad that beats the viewer has taught
  them the game is not for them.
- **Nothing has run yet.** Until a variant has been in front of real traffic, describe what
  it is meant to test, not how it performs.

## What a brief should say

1. Who it is for, and what they are doing when they see it.
2. What we want to learn from this batch.
3. Anything fixed: a theme, a headline to keep, a setting not to touch.
4. How many variants.
