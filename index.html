Why

I looked at the most-shown "tile" game ads in Meta's Ad Library. Most were 30-second videos saying one of two things: "only 1% can beat this" or "relax".

I don't think that is for lack of ideas. One idea means a playable, a video, a still for every placement and a package for every network: about twenty files. When an idea costs that much, you try few of them. So I made trying one more idea cheap.

Checked before anything goes out

Code

Is the copy true?

No percentages, no "best game", no "she's ahead" unless she really starts ahead. "Only 1%" would be refused.

Simulation

Can the viewer win?

The ad plays itself 3,000 times. Someone who follows the tutorial must win every time.

Agent

Does it read at every size?

A reviewer agent opens the stills and answers PASS or REVISE, with reasons.

Code

Does it fit every screen?

Laid out on 23 screen sizes. It fails if anything overlaps, runs off the screen or is too small to tap.

REJECTED

Can the reviewer say no?

It passed the first three variants, which told me little. So I broke two on purpose and showed them to it without saying so. This one has a headline you can barely read. It rejected both, for the right reasons.

When the game changes

The game team changes the interface and every creative you have is out of date.

I went through that four times in one evening, comparing my ad with the real game and fixing what was different. Each time one command remade everything: 24 playables, 72 stills, 6 videos, in a few minutes.
